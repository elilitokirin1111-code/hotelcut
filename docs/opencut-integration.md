# OpenCut integration

Status: M8 boundary only.

HotelCut does not claim OpenCut rendering support. Before an official stable editor or headless
API is available, M8 may implement only:

- an adapter contract
- field mapping documentation
- a list of incompatible concepts
- contract tests
- a mock adapter

No internal or unstable OpenCut implementation is copied into this repository, and no API shape
is guessed.
