# HotelCut 与剪映 AI 能力竞品分析

状态：2026-08-06 整理，用于指导产品差异化，不作为剪映功能清单的实时快照。

## 一、剪映现有 AI 能力（2026 概览）

剪映（以及其面向商业场景的成片工具）目前覆盖：

- 文字成片、图文成片、营销成片：输入文案/图文素材直接生成视频。
- 成片助手：基于内容意图自动组织素材与节奏。
- AI 视频生成：文生视频/图生视频，生成全新画面。
- 智能剪口播：自动识别口播内容并粗剪。
- 智能解说粗剪：为解说类素材自动整理剪辑点。
- 数字人播报：虚拟形象口播。
- 双语字幕 / 字幕翻译：自动字幕与多语言翻译。
- 批量 AI 成片：多个文案一次生成多条视频。
- 智能素材搜索：按语义/标签快速定位素材。

## 二、与 HotelCut 的重合点

两者在高层能力上是同构的：

| 能力           | 剪映                      | HotelCut                                |
| -------------- | ------------------------- | --------------------------------------- |
| 输入到自动成片 | 有（文字/图文/成片助手）  | 有（VideoBrief + 固定模板/AI 模板）     |
| AI 脚本与分镜  | 有（成片助手/智能剪口播） | 有（AI Director 创意/脚本/蓝图）        |
| 智能素材搜索   | 有                        | 规划中（P1）                            |
| 批量成片       | 有                        | 规划中（P1）                            |
| 字幕生成       | 有                        | 有（narration/dialogue/caption 三选一） |
| 模板/风格      | 有（模板中心）            | 有（内置模板 + AI 模板中心）            |

## 三、本质差异

HotelCut 的目标不是“通用视频编辑器”，而是“酒店运营短视频流水线”：

1. **素材资产化与深度标签**：每个酒店素材经过场景、镜头、角度、运镜、光线、构图、卖点标签化，并自动短命名，形成可检索、可复用的门店资产库。
2. **可审计的 AI 生成**：每一次 AI 操作都记录模型、提示词版本、输入摘要、失败原因；创意方向、脚本、蓝图都是不可变修订，绝不直接写入时间线。
3. **质检与交付闭环**：渲染结果必须通过 11 项质量门禁，交付 MP4/SRT/封面/工程 JSON/质量报告，适合门店标准化交付。
4. **参考视频风格学习**：从参考片学习节奏、字幕、转场、音乐规则，不复制人物、对白和品牌事实。
5. **多门店内容中台**：标签、卖点、爆款规律可以跨店沉淀和复用（长期）。

## 四、产品策略建议

- **做行业流水线，不做通用编辑器**：HotelCut 的护城河是“酒店内容数据 + 可审计自动化”，不是剪辑功能本身。
- **把剪映当精修出口**：复杂精修导出到剪映草稿（OpenCut/JianYing 适配器），不自研数字人、配音克隆、调色引擎和通用时间线。
- **优先补齐语义搜索与批量成片**：这两项用户感知最强，也是与剪映重合度最高的能力，谁先做顺谁占心智。
- **沉淀门店数据**：标签、卖点、已验证模板、参考风格是剪映无法复制的门店私有资产。

## 五、明确不做

- 不做通用免费剪辑器。
- 不做数字人、语音克隆、AI 生成视频（可对接外部能力，但不自研）。
- 不做自动发布/平台爬取（发布后可手动回填数据）。
- 不做插件市场与实时协同编辑（MVP 排除项）。
