# HotelCut 用户操作说明

本文档基于 2026-08-05 实际运行的本地前端（免登录开发模式）逐页核对编写，覆盖从打开系统到下载成片的完整路径。

## 0. 如何打开系统

- 本地开发环境：浏览器访问 <http://localhost:5173>。
- 开发模式默认启用「免登录本机模式」，打开后直接进入「我的酒店」工作台，不需要输入账号。
- 需要正式登录时（`GUEST_MODE=false`），使用种子账号：
  - 邮箱：`owner@hotelcut.example`
  - 密码：`hotelcut-local`

## 1. 界面总览

登录后默认进入 **AI 创作**。左侧导航只保留两个主入口：

- **AI 创作**（默认页）：创意、脚本、参考视频、素材四种创作模式
- **素材库**：上传、分析、打标签、删除素材

其余功能收进右上角「⋯ 更多菜单」：工作台 / 视频项目（自动剪辑）/ 模板中心 / 酒店与品牌 / 渲染中心 / 操作记录 / 设置。

右上角全局按钮：

- 「管理素材」：跳转到素材库
- 「创建视频」：跳转到 AI 创作（注意：不是自动剪辑，而是 AI 创作入口）
- 「帮助」「AI 助手」：目前是占位按钮（提示“待接入”），点击无功能

## 2. 工作台（首页）

展示三块内容：

- 酒店内容准备度：素材是否就绪、是否可以直接成片
- 最近视频项目：已有项目的快捷入口
- 渲染队列：最近渲染任务的实时状态

首页常用快捷按钮：创建视频、上传新素材、查看全部项目、查看交付记录。

## 3. 素材库（推荐从这里开始）

素材库是自动剪辑的前提。操作顺序：

1. 点击「上传新素材」，选择酒店实拍视频（支持大文件分片上传，浏览器端会先算 SHA-256）。
2. 上传完成后系统自动进入分析队列，素材状态依次为：`上传中 → 分析中 → ready`。
3. 点击素材查看分析详情，包括：
   - 基础信息（分辨率、帧率、时长、码率）
   - AI 简短命名：新分析素材会得到 4–10 字的自动命名；老素材按「场景类别·卖点」兜底命名
   - 深度视觉分析（v2）：场景描述、质量分、卖点、AI 标签（`room`、`service`、`exterior`、`welcome` 等），以及每个分镜的角度、运镜、光线、构图和主体
   - 转写（当前开发环境为 mock 转写，真实转写需开启 faster-whisper）
   - 场景片段列表、缩略图/代理视频/音频等衍生文件
   - 分析日志（可查看每一步耗时和失败原因）
4. 分析失败时点击「重试分析」；也可以手动添加标签片段（选中时间段 + 打标签）。
5. 删除素材：勾选素材卡片左上角选择框，点击右上角「删除选中（N）」批量删除；删除会级联清理分析记录和衍生文件。

> **关键**：自动剪辑按“模板必需标签”匹配素材。当前 42 个演示素材大多只有视觉分析标签，个别模板（如 `host-broll` 需要 `welcome`/`booking`）仍凑不齐。如果生成时报 400，多半是缺标签，去素材库给素材补对应标签即可。

## 4. 视频项目（自动剪辑）

这是「输入需求 → 自动成片」的主流程。

### 4.1 填写需求单

- 项目标题（必填）
- 发布平台：抖音 / 小红书 / 视频号 / 其他
- 成片时长（秒）：受模板时长范围约束
- 画面调性（必填）：例如“温暖明亮、专业亲和”
- 目标客群：例如“周末亲子客群”
- 传播目标：例如“突出湖景房与早餐，提升周末咨询”
- 行动引导（CTA）：例如“联系酒店了解周末房态”

### 4.2 选择剪辑模板

右侧卡片显示每个模板的时长范围和“建议素材标签”：

| 模板                            | 必需画面                                   |
| ------------------------------- | ------------------------------------------ |
| `hotel.host-broll` 主持人+B 卷  | welcome、room、booking、lobby、service     |
| `hotel.room-montage` 客房蒙太奇 | exterior、room、bathroom、facility、detail |
| `hotel.promotion` 酒店促销      | exterior、room、service、promotion         |

音乐槽位在没有背景音乐素材时会自动回退到源视频环境音，不会阻塞生成。

除了内置模板，模板中心用 AI 生成的模板也会出现在这里（卡片带「AI」角标）。选择一个 AI 模板后，系统会按该模板的分镜标签重新自动选片。

「已保存项目」列表支持勾选后批量删除项目（项目修订和渲染记录会一并删除）。

### 4.3 生成并保存

1. 点击「生成并保存剪辑项目」。
2. 右侧「已保存项目」出现新项目；生成结果卡片展示：匹配槽位数、使用的素材数、编译警告。
3. 如果提示“自动剪辑预检未通过，缺少必需画面”，按提示去素材库补标签后点「重试自动剪辑」。
4. 预览确认后点击「进入 Studio 编辑」。

右上角「AI 剪辑策划 / 生成真实方案」会调用已配置的大模型生成钩子、叙事节奏、镜头策略和模板推荐；未配置模型时该功能不可用。

## 5. Studio 编辑器（核心剪辑界面）

Studio 是逐镜头编辑的工作台：

- 顶部：撤销 / 重做、返回项目列表（自动保存）
- 左侧「场景列表」：按时间顺序列出每个镜头（如 `01 promo.exterior · 4.4s`），点击可选中
- 右侧「局部调整」：四个页签
  - 镜头：裁切起止点，点「应用裁切」生效；可从下拉列表「替换为 …」换成同酒店其他素材
  - 文案：修改字幕/标题
  - CTA：修改行动引导
  - 音乐：调整背景音乐
- 预览区：竖版播放/拖动进度

所有修改会防抖自动保存为不可变修订；多人/多标签页冲突时会提示重新加载。

## 6. 渲染中心（出片交付）

1. 左侧「视频项目」选择要渲染的项目（默认当前最新修订）。
2. 点击「渲染当前修订 N」提交任务。
3. 「渲染记录」中查看任务状态：准备素材 → 渲染 → 质量检查 → 完成；失败可「重试渲染」，进行中可「取消渲染」。
4. 完成后右侧展示：
   - 质量报告：11 项强制质检（时长、黑帧、静音等）及评分
   - 交付产物：MP4、SRT 字幕、封面、标准化工程 JSON 等，点「生成下载链接」获取短时链接下载
   - 处理日志：每一步的详细日志
5. 清理任务：已完成/失败/已取消的任务可勾选后点「删除选中（N）」批量删除；进行中的任务需先取消。

## 6.1 模板中心（AI 生成模板）

- 入口：更多菜单 → 模板中心。
- 「用 AI 分析生成模板」：系统读取本酒店已分析素材的标签、卖点和画面描述，调用已配置大模型生成按时间轴分镜的专属模板；生成后可立即在「视频项目」里选用。
- 模板列表支持勾选批量删除。
- 可在「设置 → 界面设置」关闭「启用 AI 模板中心」，关闭后导航与创作页都不再显示模板入口。

## 7. AI 创作（创意辅助）

「AI 创作」提供四个入口：

- 从创意开始：把一句想法扩成脚本、分镜和拍摄清单
- 从脚本开始：校验信息、补强钩子、转成剪辑蓝图
- 模仿参考视频：学习叙事、节奏和镜头语言（不复制原片内容）
- 从现有素材开始：评估素材覆盖率，生成品牌/转化/IP 方向

创建项目后会**自动进入下方「创意助手」**：输入一句创意，即可生成三套方向并转换为可编辑脚本；脚本确认后继续素材匹配、动态蓝图和 A/B/C 成片，成片卡片上有「在 Studio 中打开成片」直接进入剪辑。

如果不想走 AI 策划，页面顶部提供「**直接开始剪辑（素材自动成片）**」：一键进入视频项目，用现有素材自动成片并打开 Studio。

**纯画面/字幕模式**：参考视频或脚本场景没有口播对白时，AI 会自动选择「画面 + 字幕」表达——每个镜段生成一句字幕文案并跨整段持续显示，不会只出现在第一段。成片后在 Studio 的「文案」标签里可以逐段修改，渲染时字幕会随 SRT 一并交付。

首次使用前到「设置」里配置大模型：

- 服务类型：阿里云百炼 / OpenAI / OpenAI 兼容
- 调用协议、API Base URL、模型名、推理强度
- API Key（只保存在服务端，不回显）
- 「保存并测试真实连接」验证连通性

## 8. 操作记录

「操作记录」展示当前酒店的运营审计流水（当前为审计入口，记录会随后续里程碑补充）。

## 9. 常见问题

### 自动剪辑返回 400 / “缺少必需画面”

原因：模板必需标签在素材中不满足。处理：在素材库给对应素材添加缺失标签（如 `exterior`、`promotion`），再点「重试自动剪辑」。

### 转写内容是“HotelCut 测试素材”

开发环境默认 `ANALYSIS_TRANSCRIPTION_PROVIDER=mock`。要使用真实转写，将环境变量改为 `faster-whisper` 后重启分析 Worker（首次会下载模型）。

### AI 功能不可用 / 报模型错误

到「设置」检查模型配置：服务类型、Base URL、模型名、API Key，并用「保存并测试真实连接」验证。

### 自动命名/深度标签没有出现

深度标签和自动命名由 AI 分析 v2 生成：**重新上传或「重新进行 AI 分析」的素材**才会走新提示词；历史素材显示按「类别·卖点」生成的兜底名称。

### 纯画面场景的字幕只在第一段出现？

已修复：同一镜段的多个子镜头现在共用一条字幕并覆盖整段时长；AI 模板和动态蓝图都按此规则生成。在 Studio「文案」标签可逐段修改字幕文案。

### 帮助按钮没反应

「帮助」和「AI 助手」目前是待接入占位，后续会接入操作说明与问答助手。

### 渲染一直停在“准备素材”或失败

在「处理日志」中查看具体失败原因，修正后「重试渲染」；多次失败可反馈给开发（渲染 Worker 日志位于 `apps/render-worker` 容器）。
